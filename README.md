# ExCommission

代理与佣金业务后端。保存代理规则，计算奖励和佣金，处理审批、结算及报表。

![ExCommission主要功能](docs/images/features.svg)

管理页面在独立工程 [ExCommission-Web](https://github.com/ex-business/ExCommission-Web)。运营账号和会员账号分别由各自的身份系统管理。
